# 答桥 AnswerBridge

一款 Windows 桌面助手：在电脑上输入问题或截取屏幕，模型生成答案后，可通过局域网同步到手机网页。支持系统声音和麦克风采集，并通过火山引擎语音识别将声音转为文字。

## 当前状态

这是开发中的 MVP。桌面端与手机之间的配对和流式答案经过本地模拟测试；真实手机网络、真实语音服务、截图视觉模型和不同显示器仍需分别验收。程序默认以演示模式启动，不会调用真实模型。

## 启动

需要 Windows 和 Node.js：

```powershell
npm ci
npm run build
npm start
```

开发模式使用 `npm run dev`。运行测试使用 `npm test`，脚本语法检查使用 `npm run check`，构建 Windows 目录使用 `npm run package:win`。

## 使用方式

1. 电脑与手机连接可互通的局域网，打开答桥并用手机扫描二维码；网络不通时检查所选网卡、防火墙和 Wi-Fi 隔离。
2. 在“软件设置 / 加载 Skill”中选择服务商，填写接口地址、API Key 和模型 ID，切换到真实模型模式并保存。连接测试会发送一条简短文字并可能产生费用；通过不代表图片能力通过。
3. 在电脑输入文字，或通过快捷键截取屏幕；支持图片输入的模型可直接处理截图。截图默认跟随当前回答模型，也可在高级设置中单独配置。
4. 答案逐步显示在电脑与已连接的手机上。语音输入需另行配置火山语音识别服务。

全屏截图默认为单独按下并松开 `Ctrl`；`Alt+D` 用于框选截图；`Home` 隐藏或显示窗口，在答桥编辑框内不会触发窗口切换。截图前注意检查画面内容，截图会发送到所选云端服务商。

## 数据和安全

- 通过设置保存的密钥与 Skill 快照由 Windows 本机安全存储保护；不应将 `.env`、用户配置、密钥、个人 Skill、测试截图或日志提交到仓库。
- 电脑和手机默认通过局域网 HTTP/WebSocket 通信；请只在可信网络中使用，不要直接暴露到公网。云服务的处理与保留政策以对应服务商为准。
- 演示答案会明确标为“演示答案”。真实服务的模型可用性、价格和响应时间取决于具体服务商和账户。

## 项目目录

`electron/` 为 Windows 桌面入口与截图；`server/` 为模型、配对与语音处理；`web/` 为电脑和手机页面；`tests/` 为本地自动化测试；`scripts/` 为构建与检查脚本。
